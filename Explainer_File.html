🎯 Overview

The SPC Dashboard is a powerful tool for monitoring maintenance performance across multiple airline stations using Statistical Process Control (SPC) methodology. It implements Wheeler's XmR charts and rules for detecting process shifts and calculating Natural Process Limits.

🚀 Getting Started

1

Start the Dashboard

Windows: Double-click START_DASHBOARD.bat

Mac/Linux: Run ./start_dashboard.sh

The dashboard will open automatically in your browser at http://localhost:8000

2

Load Sample Data

Click "Load Test Data" to view sample maintenance metrics from 3 stations (AUS, DAL, HOU) from January 2023 to present.

3

Upload Your Data

Use the file upload button to load your own CSV data. The dashboard supports two formats and will automatically detect which one you're using.

📊 Weekly Mode - SPC Charts

When you load weekly data, the dashboard displays three types of charts grouped together for each measure:

X Chart (Individuals)

Monitors process location (average performance)

  • Center Line (CL) = mean of phase data
  • UCL/LCL = CL ± 2.66 × mR̄
  • Points beyond limits indicate special causes

mR Chart (Moving Range)

Monitors process variation (consistency)

  • Center Line = average moving range
  • UCL = 3.268 × mR̄
  • LCL = 0 (minimum)

Distribution Chart

Histogram with normal curve overlay

  • Auto-linked to phase slider
  • Bins automatically recomputed
  • Shows data distribution shape

Phase Zoom Control

Use the "Phases to Display" slider to focus on recent performance:

  • Default: Shows all phases from January 2023
  • Adjustable: Move slider to show fewer phases
  • Synchronized: All three charts update together

Wheeler's Rules Implemented

  • Rule #1: Point beyond control limits (outside UCL/LCL)
  • Rule #2: 2 of 3 consecutive points beyond 2σ on the same side
  • Rule #4: 7 consecutive points on one side of centerline

📈 Daily Mode - Interactive Bar Charts

When you load daily data, the dashboard switches to interactive Plotly.js bar charts with enhanced features:

Interactive Features

  • Zoom: Mouse wheel to zoom in/out
  • Pan: Click and drag to move around
  • Slider: 7-30 day range control
  • Reset: Click home icon to reset view

Visual Enhancements

  • Weekend Highlighting: Saturday/Sunday in Southwest red
  • Day Labels: 3-letter day abbreviations
  • Dynamic Limits: UCL/LCL calculated from visible data
  • Color Coding: Out-of-control points in red

Daily Slider Control

The "Days to Display" slider provides explicit control over the date range:

  • Range: 7 to 30 days
  • Default: Shows last 7 days
  • Dynamic: Table updates with slider changes
  • Synchronized: Chart and table stay in sync

Data Table

Below each daily chart is a synchronized data table showing:

  • Rate: Daily metric values
  • MEL: Minimum Equipment List counts
  • AC*: Aircraft counts

The table automatically updates when you use the slider or zoom/pan the chart.

📁 Supported Data Formats

Format 1: Filename as Measure Name

maintenance_cancels.csv Format 1 
timestamp,station,metric_value
2023-01-02,Austin,2.5
2023-01-02,Dallas,3.1
2023-01-09,Austin,2.8

The filename becomes the measure name. Use this format when you have one measure per file.

Format 2: Standard Format

all_measures.csv Format 2 
station,measure,date,value
AUS,Maintenance Cancels,2023-01-02,2.5
DAL,Maintenance Cancels,2023-01-02,3.1
AUS,Maintenance Cancels,2023-01-09,2.8

Use this format when you have multiple measures in one file.

Date Formats Supported: YYYY-MM-DD, M/D/YYYY, YYYY/M/D, M-D-YYYY

🔧 Troubleshooting

CSV Upload Issues

Built-in CSV Format Checker: Navigate to http://localhost:8000/csv_format_checker.html to diagnose format issues and get specific fix suggestions.

Common Issues:

  • Wrong date format: Use YYYY-MM-DD format
  • Text in numeric columns: Ensure all values are valid numbers
  • Missing headers: Check that column names match exactly
  • Empty rows: Remove any blank lines in your CSV

Chart Display Issues

  • Charts not loading: Make sure the server is still running
  • Browser cache: Try a hard refresh (Ctrl+F5)
  • Console errors: Press F12 to check for JavaScript errors

Server Issues

  • Port already in use: Edit server.py and change the PORT number
  • Python not found: Ensure Python 3.7+ is installed and in your PATH
  • Permission denied: Try running as administrator (Windows) or with sudo (Mac/Linux)
